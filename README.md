# Data Analyst — Carnet d'apprentissage

Suivi quotidien de ma progression en Python appliqué à la data analyse, 
dans le cadre de ma formation en génie informatique et télécommunications 
à l'Institut Polytechnique de Saint-Louis (IPSL).

## Contenu

| Fichier | Notions abordées |
|---|---|
| jour1-2 | Variables, types, listes, tuples, sets, dictionnaires |
| jour3-4 | Conditions, boucles, fonctions |
| jour5-6 | Lecture/écriture de fichiers |
| jour7-8 | Manipulation de fichiers CSV (module csv) |
| jour7_pandas, jour9-10 | Introduction à Pandas (DataFrame, groupby, value_counts) |

## Objectif

Ce dépôt documente ma montée en compétences pas à pas. Il ne s'agit pas 
d'un projet abouti mais d'exercices progressifs, en vue de me spécialiser 
en data analyse / data science.
